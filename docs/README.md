# 목소리 거짓말탐지기 (웹앱)

폰 브라우저에서 바로 쓰는 재미용 음성 분석 앱입니다. 설치·서버 없이 `index.html` 하나로 동작합니다.

## 폰에서 쓰는 법
1. GitHub 저장소 → Settings → Pages → Source: "Deploy from a branch" → 브랜치 선택, 폴더 `/docs` → Save
2. 1~2분 뒤 `https://woodong96.github.io/SACOT/` 접속 (마이크는 https에서만 작동)
3. 브라우저 메뉴 → "홈 화면에 추가" 하면 앱처럼 실행됩니다.

## 동작 원리
1. 기준 측정: 진실을 5초간 말해 평소 목소리를 기록
2. 질문에 대답하면 기준 대비 아래 항목을 비교해 "거짓말 지수"(0~100) 계산
   - 목소리 높이(피치) 상승, 떨림(지터), 억양 흔들림, 음량 불안정, 대답 전 머뭇거림, 말 끊김

모든 분석은 기기 안에서만 하며 녹음은 저장·전송하지 않습니다.
※ 음성 스트레스 분석은 과학적으로 거짓말을 판별하지 못합니다. 오락용으로만 쓰세요.
